# **GOST Auto Format**

## Описание

**GOST Auto Format** — это приложение, предназначенное для автоматического форматирования научных и дипломных работ в соответствии с требованиями ГОСТа. Приложение анализирует структуру документа, идентифицирует ключевые элементы (заголовки, таблицы, списки, ссылки и т. д.) и применяет соответствующие стили и форматирование.

## Структура проекта

Проект состоит из нескольких модулей:

```
GOST_Auto_Format/
│
├── main.py             # Основной файл, который запускает процесс форматирования.
├── formatting.py       # Модуль для загрузки, анализа и форматирования документов.
├── interface.py        # Модуль для создания графического интерфейса с помощью tkinter.
├── requirements.txt    # Список всех зависимостей для проекта.
└── venv/               # Виртуальное окружение с установленными зависимостями.
```

### Основные файлы:

1. **main.py**
   - Это основной файл проекта. Он запускает все ключевые процессы, такие как загрузка документа, анализ текста и его форматирование.
2. **formatting.py**
   - Этот файл содержит функции, которые отвечают за обработку и форматирование текста документа:
     - `load_docx(file_path)` — Загружает текст из документа .docx.
     - `identify_elements(text)` — Идентифицирует ключевые элементы текста, такие как заголовки и списки.
     - `format_document(file_path)` — Применяет стили и форматирование к элементам документа.
3. **interface.py**

   - Этот файл создаёт графический интерфейс с использованием библиотеки `tkinter`, где пользователи могут загружать документ для автоматического форматирования.
   - `run_interface()` — Основная функция для запуска интерфейса.

4. **requirements.txt**
   - Этот файл содержит список зависимостей, необходимых для проекта. Он используется для установки всех требуемых библиотек с помощью команды:
     ```bash
     pip install -r requirements.txt
     ```

## Установка

### Шаги для установки и запуска приложения:

1. Клонируйте репозиторий или скачайте проект на свой компьютер.

2. Создайте виртуальное окружение:

   ```bash
   python -m venv venv
   ```

3. Активируйте виртуальное окружение:

   - **Windows**:
     ```bash
     .\venv\Scripts\activate
     ```
   - **macOS/Linux**:
     ```bash
     source venv/bin/activate
     ```

4. Установите все необходимые зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Запустите приложение:
   ```bash
   python main.py
   ```

### Графический интерфейс:

При запуске приложения откроется окно, где можно выбрать документ для форматирования. После выбора документа приложение автоматически выполнит форматирование и сохранит результат в новый файл.

## Функциональность

1. **Загрузка документа:**
   Пользователь может загрузить документ формата `.docx`, и система извлечет текст из файла.

2. **Анализ и разметка текста:**
   Приложение анализирует текст документа, выделяет ключевые элементы, такие как заголовки, списки, таблицы, ссылки и т. д.

3. **Форматирование:**
   На основе выделенных элементов приложение применяет стили в соответствии с требованиями ГОСТа (например, шрифты, отступы, выравнивание).

4. **Сохранение документа:**
   Отформатированный документ сохраняется в новый файл с тем же названием, но с приставкой "\_formatted".

## Пример использования

1. Запустите приложение, выбрав документ для форматирования через интерфейс.
2. Программа проанализирует и отформатирует текст в соответствии с ГОСТом.
3. Отформатированный документ будет сохранен с новым именем (например, `document_formatted.docx`).

## Требования

Для работы приложения необходимы следующие зависимости:

- Python 3.x
- `numpy`
- `pandas`
- `spacy`
- `tensorflow`
- `transformers`
- `python-docx`
- `tkinter` (входит в стандартную библиотеку Python для Windows и macOS)

Для установки зависимостей можно использовать команду:

```bash
pip install -r requirements.txt
```
