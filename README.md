# **GOST Auto Format**

## Описание проекта

**GOST Auto Format** — это интеллектуальное приложение на основе нейронных сетей, предназначенное для автоматического форматирования научных и дипломных работ в соответствии с требованиями ГОСТа. Приложение анализирует структуру документа, идентифицирует ключевые элементы (заголовки, таблицы, списки, ссылки и т.д.) и применяет соответствующие стили и форматирование согласно выбранному стандарту.

## Проблема и решение

### Проблема
Студенты и научные работники часто сталкиваются с трудностями при оформлении работ по строгим требованиям ГОСТа. Процесс форматирования требует значительных временных затрат и внимания к деталям, а несоответствие требованиям может привести к отклонению работы.

### Решение
GOST Auto Format использует технологии машинного обучения для автоматического распознавания структуры документа и его элементов, после чего применяет правильное форматирование согласно выбранному стандарту ГОСТ. Это позволяет:
- Сэкономить десятки часов ручного форматирования
- Исключить человеческие ошибки
- Гарантировать соответствие документа всем формальным требованиям

## Поддерживаемые стандарты

- ГОСТ 7.32-2017 (Отчет о НИР)
- ГОСТ Р 7.0.5-2008 (Библиографическая ссылка)
- ГОСТ 7.1-2003 (Библиографическая запись)

## Технологический стек

- **Языки программирования:** Python 3.x
- **Нейронные сети:** BERT (DeepPavlov/rubert-base-cased)
- **Фреймворки:** PyTorch, Transformers
- **Обработка документов:** python-docx
- **Интерфейс:** Tkinter
- **Анализ данных:** NumPy, Pandas

## Принцип работы

### 1. Подготовка данных
Система использует размеченный датасет документов для обучения модели, где каждый абзац классифицирован по типу (заголовок, обычный текст, список и т.д.).

### 2. Обучение модели
Нейронная сеть на основе RuBERT обучается классифицировать элементы документа, анализируя их содержание, стиль и контекст.

### 3. Анализ документа
При загрузке пользовательского документа система:
- Разбивает документ на абзацы
- Классифицирует каждый абзац с помощью обученной модели
- Определяет структуру документа и взаимосвязи между элементами

### 4. Применение форматирования
На основе классификации каждому элементу применяются правила форматирования в соответствии с выбранным стандартом ГОСТ:
- Шрифты и размеры текста
- Отступы и интервалы
- Выравнивание текста
- Стили заголовков и списков
- Оформление таблиц и рисунков

### 5. Сохранение результата
Отформатированный документ сохраняется в новый файл, готовый к использованию.

## Установка

### Системные требования
- Python 3.7 или выше
- 4 ГБ ОЗУ (рекомендуется 8 ГБ для обучения модели)
- 2 ГБ свободного места на диске

### Шаги для установки и запуска приложения:

1. Клонируйте репозиторий или скачайте проект на свой компьютер:
   ```bash
   git clone https://github.com/yourusername/gost-auto-format.git
   cd gost-auto-format
   ```

2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   ```

3. Активируйте виртуальное окружение:
   - **Windows**:
     ```bash
     .\venv\Scripts\activate
     ```
   - **macOS/Linux**:
     ```bash
     source venv/bin/activate
     ```

4. Установите все необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

5. Запустите приложение:
   ```bash
   python main.py
   ```

## Использование приложения

1. **Запуск приложения:** Выполните `python main.py` для запуска графического интерфейса.

2. **Выбор стандарта ГОСТ:** Выберите необходимый стандарт форматирования из списка поддерживаемых.

3. **Загрузка документа:** Нажмите кнопку "Обзор..." и выберите документ Word (.docx) для форматирования.

4. **Выбор места сохранения:** Укажите путь для сохранения отформатированного документа или используйте предложенный по умолчанию.

5. **Запуск форматирования:** Нажмите кнопку "Форматировать документ" и дождитесь завершения процесса.

6. **Предварительный просмотр:** Используйте функцию предварительного просмотра для проверки ожидаемых изменений перед форматированием.

7. **Обучение модели (опционально):** Для продвинутых пользователей доступна возможность обучить модель на собственных данных с помощью кнопки "Обучить новую модель".

## Обучение собственной модели

Если вы хотите обучить модель на собственных данных:

1. Поместите примеры документов:
   - Соответствующие ГОСТу в папку `data/gost_examples/`
   - Не соответствующие ГОСТу в папку `data/non_gost_examples/`

2. Запустите подготовку данных:
   ```bash
   python data_processing.py
   ```

3. Запустите обучение модели через интерфейс или с помощью команды:
   ```bash
   python training.py
   ```
